# Cooking Book App

Адаптивный каталог для полной базы блюд: рецептов из соседней директории
`recipes/` и идей без заполненного рецепта из `catalog/dishes.yaml`.
Приложение читает данные на сервере при каждом обновлении страницы, поэтому
после изменения базы не требуется пересборка или перезапуск.

## Локальная разработка

Требуется Node.js 20.9 или новее.

```bash
npm install
npm run dev
```

По умолчанию приложение читает:

- рецепты из `../recipes`;
- блюда-идеи из `../catalog`;
- категории из `../reference`.

Пути можно изменить через `RECIPES_DIR`, `CATALOG_DIR` и `REFERENCE_DIR`.
После изменения базы нажмите кнопку обновления в шапке или обновите страницу.

## Запуск через Docker

Запускайте команду из директории `cooking-book-app`:

```bash
docker compose up --build -d
```

Приложение откроется на `http://localhost:3000`. В `compose.yaml` каталоги
`../recipes`, `../catalog` и `../reference` подключены к контейнеру только для
чтения.

Перед публикацией задайте внешний адрес приложения для корректных карточек
предпросмотра:

```bash
SITE_URL=https://recipes.example.com docker compose up --build -d
```

Для обновления базы достаточно изменить Markdown-рецепт или `dishes.yaml` на
сервере. Пересобирать Docker-образ не нужно.

## Публикация

Не выставляйте порт Next.js напрямую в интернет. Разместите перед приложением
reverse proxy с HTTPS и ограничением доступа — например, Caddy, nginx,
Tailscale или Cloudflare Access.
