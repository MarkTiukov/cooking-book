# Cooking Book

Локальная база структурированных рецептов, предназначенная для людей и агентов. Полные рецепты хранятся плоским списком в `recipes/*.md`: один файл соответствует одному блюду. Известные блюда без состава и инструкции находятся в `catalog/dishes.yaml` как идеи для будущего наполнения и составления меню.

## Добавление блюда

Передайте агенту текст или собственное описание рецепта и попросите использовать `$add-recipe`. Скилл извлечёт доступные сведения, проверит базу на дубликаты и одним сообщением запросит недостающие обязательные данные. После уточнений он сохранит рецепт и запустит валидатор.

Пример запроса:

```text
Используй $add-recipe и добавь шакшуку: на 2 порции, 4 яйца, банка томатов,
луковица, соль и зира. Лук обжарить, добавить томаты и специи, затем яйца;
готовить под крышкой около 8 минут.
```

Схема данных описана в `reference/recipe-schema.md`, а инструкции агентам — в `AGENTS.md`.
