# Книга рецептов

Этот проект — структурированная база рецептов для ответов на запросы о блюдах, меню и закупках.

## Источники данных

- Рецепты находятся только в `recipes/*.md`; вложенные директории не используются.
- Блюда без полноценного рецепта находятся в `catalog/dishes.yaml` со статусом `idea`.
- Полная схема рецепта описана в `reference/recipe-schema.md`.
- Допустимые категории находятся в `reference/categories.yaml`.
- Канонические теги и их отображаемые названия находятся в `reference/tags.yaml`.
- Допустимые единицы и коэффициенты пересчёта находятся в `reference/units.yaml`.
- Канонические ингредиенты, синонимы и отделы магазина находятся в `reference/ingredients.yaml`.

При работе с рецептами считай структурированный YAML frontmatter источником истины для фильтрации и расчётов, а Markdown-текст — источником шагов приготовления и примечаний.

## Общие правила

- Перед ответом, зависящим от базы, сканируй все файлы `recipes/*.md`, а не отдельную директорию по названию категории.
- При составлении меню также сканируй `catalog/dishes.yaml`. Идеи можно предлагать как блюда, но явно отмечай отсутствие рецепта.
- Не придумывай наличие рецепта в базе. Если подходящих вариантов недостаточно, явно сообщи об этом.
- Для объединения закупки сопоставляй ингредиенты по `ingredients[].id`, а не по отображаемому названию.
- Не включай в закупку ингредиенты с `purchasable: false` в `reference/ingredients.yaml`.
- Масштабируй числовые количества пропорционально числу порций. Значения `to-taste` не масштабируй.
- Складывай только совместимые единицы. Используй коэффициенты из `reference/units.yaml`; неоднозначные упаковки, пучки и банки оставляй отдельными позициями, если нет явного коэффициента.
- Учитывай аллергены и явно заданные пользователем ограничения раньше предпочтений и разнообразия.
- Для фильтрации используй идентификатор тега, а в ответах пользователю — его `name` из `reference/tags.yaml`.
- Не изменяй базу при запросе только на чтение, подбор меню или список закупки.
- Не строй точный список закупки или инструкцию приготовления для блюда со статусом `idea`. Если такое блюдо попало в меню, перечисли его отдельно как позицию с неизвестным составом.
- Для добавления блюда используй проектный скилл `$add-recipe`.

После изменения базы запусти:

```bash
python3 scripts/validate_recipes.py
```
